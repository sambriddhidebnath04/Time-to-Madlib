# Time-to-Madlib 📝✍️

A simple Mad Libs game that runs in any browser, on phone or PC. 

Pick a story, fill in the words without seeing it, then read the silly result.

Hope you enjoy this silly little game! (≧∇≦)ﾉ

Built with plain HTML, CSS and JavaScript.


👽 Play Live version: https://sambriddhidebnath04.github.io/Time-to-Madlib/ 👽

Or run it locally by downloading the three files and opening index.html in a browser.


How it works:


~ Choose a story, or tap Surprise me for a random one.

~ Type a word for each prompt (for example, "Give me an adjective"). 
Press Enter or tap Next word.

~ Read the finished story with your words highlighted.

~ Use Read it aloud to hear it, Same story, new words to replay it, or Pick another to go back to the list.
